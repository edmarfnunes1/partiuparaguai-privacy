Política de Privacidade – PartiuParaguai

Última atualização: 17 de julho de 2026

O aplicativo PartiuParaguai foi desenvolvido pela Innovaqa Solutions com o objetivo de auxiliar viajantes brasileiros no controle de compras realizadas no Paraguai, oferecendo conversão de moedas e simulação de tributação.

1. Coleta de dados

O PartiuParaguai não coleta, transmite, armazena ou compartilha dados pessoais dos usuários.

O aplicativo não solicita:

  • Nome
  • E-mail
  • CPF
  • Número de telefone
  • Localização
  • Contatos
  • Fotos
  • Arquivos
  • Dados bancários
  • Qualquer outra informação pessoal.

2. Armazenamento das informações

As informações cadastradas pelo usuário, como:

  • compras realizadas;
  • valores das cotações;
  • configurações do aplicativo;

são armazenadas exclusivamente no próprio dispositivo utilizando o armazenamento local do Android.

Esses dados não são enviados para servidores externos.

3. Compartilhamento de dados

O PartiuParaguai não compartilha informações com terceiros.

4. Serviços de terceiros

O aplicativo não utiliza:

  • serviços de análise (Analytics);
  • publicidade;
  • rastreamento;
  • ferramentas de marketing;
  • serviços de coleta de dados.

5. Conexão com a internet

O aplicativo foi desenvolvido para funcionar integralmente offline.

O acesso à internet não é necessário para utilização de suas funcionalidades principais.

6. Segurança

Como nenhuma informação é enviada para servidores externos, todos os dados permanecem armazenados apenas no dispositivo do usuário.

7. Alterações desta Política

Esta Política de Privacidade poderá ser atualizada futuramente para refletir novas funcionalidades do aplicativo.
